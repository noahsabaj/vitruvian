# 2026-06-30 — Review, JEPA modernization, cloud retrain, and the reward-decoupling pivot

A long session in three acts, ending with a strategic reorientation.

## 1. Code review → root-cause fixes

Ran a high-effort review with custom axes (correctness + drift-from-purpose).
Fixed the root causes and remaining findings, all with tests:

- **RC1** — k-step rollout target off-by-one: the world model was scoring the
  wrong future frame. Fixed the index; added a perfect-predictor test.
- **RC2** — `is_goal_self` always False → `is_goal_reached=(t+1==g)` + IQL cuts
  the bootstrap at terminal.
- **RC3** — plan-time history/action misalignment in MPPI (+ HS-1 alignment);
  mirrored in `plan`/`eval`.
- **F1** — episode-aware train/val split (was leaking windows across the split).
- Plus **E1** frozen-encoder `train()` overrides, lazy cls backbone, and
  doc-fidelity fixes.

55 tests + `mypy --strict` clean.

## 2. "What if JEPA instead?" → deep research → M5 modernization

Deep-research sweep of ~H1-2026 JEPA work + direct arXiv reads. Adopted the
"adopt-now" recommendations:

- **SIGReg** anti-collapse (LeJEPA, arXiv:2511.08544), replacing the VICReg std
  term. Theory backing arXiv:2605.26379 (Gaussian latents → identifiability →
  well-posed latent planning).
- **Proprio-as-conditioning** + a **visual-only prediction target** — so the
  planner's goal is a plain image embedding and the MPPI cost is one clean
  space. `proprio_dropout=0.5` for robustness to the proprio-free future of a
  plan rollout.
- **Kept DINOv3** over a V-JEPA video encoder (FAIR planning study
  arXiv:2512.24497 shows DINO-image wins for JEPA-WM planning). Explicitly did
  *not* swap the encoder, unfreeze, or add causal masking (the "no's").

Checkpoints now stamp `arch_version:2`; pre-2 ckpts warn on load.

## 3. Cloud retrain (in progress) + the pivot

- Stood up a global **arXiv MCP server** so paper-pulls are first-class from now
  on (no more copy-paste).
- Regenerating the **full pipeline from scratch** on a Lightning.ai **RTX PRO
  6000** (Blackwell, 96 GB): PPO walker → parallel collect (16 workers) →
  DINOv3 precompute → JEPA train (new objective) → eval. Resumable, detached.
  PPO walker hit **eval_reward ~12.6** (vs M1's +3.70) at ~80k sps.
  *[Status at write time: Stage 2 collect.]*
- A critique framed around **Yann LeCun's** positions surfaced the real gap: we
  lean on task reward, and we haven't shown the planner beats the policy that
  trained it. → **[ADR 009](../decisions/009-thesis-question-milestones.md)**:
  reorient to thesis-question milestones (Q1–Q5), **decouple the world model
  from task reward** (intrinsic cost + intrinsic motivation + goal-conditioned
  planning). The reward-trained run becomes the **baseline/control**, not the
  destination.
